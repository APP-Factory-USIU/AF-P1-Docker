# Slide artwork

- `classroom.png`: generated with OpenAI image generation for this workshop.
  Decorative illustration, not a depiction of a real class or an architecture diagram.
- `vm-containers.png`: generated teaching illustration comparing separate guest
  kernels with a shared Linux kernel. Simplified conceptual stacks, not a complete
  runtime implementation. Its labels were checked against the Docker and Red Hat
  references in the corresponding slide notes.
- `docker-architecture.webp`: Docker's official architecture illustration, downloaded
  from https://docs.docker.com/get-started/images/docker-architecture.webp on
  5 November 2026. Source page: https://docs.docker.com/get-started/docker-overview/.
  Copyright Docker Inc.; included with attribution for educational use.
  This third-party artwork is not covered by the repository's MIT code license.

The PPTX contains editable lesson text and speaker notes. `lesson.json` contains
the ordered slide content, prompts, and source links for future revisions.
The app uses a copy of the classroom illustration in `app/static/classroom.png`.
Both the app and deck use navy `#0B1220`, cyan `#38D5E6`, warm white `#F5F2E9`,
and coral `#FF8C68`.
